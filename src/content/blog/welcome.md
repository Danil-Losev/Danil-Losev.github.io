# Работа с Linux

Например:

```bash
sudo pacman -Syu
```

А вот JavaScript:

```js
const name = 'Danil';

console.log(`Hello, ${name}!`);
```

И TypeScript:

```ts
interface User {
  name: string;
  age: number;
}

const user: User = {
  name: 'Danil',
  age: 25,
};
```

И C:

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, world!\n");
    return 0;
}
```
